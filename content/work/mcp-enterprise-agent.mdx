## The constraint

Model Context Protocol servers grant LLM agents access to real enterprise assets — databases, filesystems, internal APIs. Every server is a trust boundary. Directory traversal, over-scoped tokens, and missing audit trails are not edge cases; they're the default failure mode at scale.

## The approach

I built an enterprise MCP server with three non-negotiable properties:

1. **Absolute path sandboxing** — every filesystem operation resolves against a fixed root; `../` traversal triggers immediate abort with `INVALID_PARAMS`
2. **Read-only database enforcer** — PostgreSQL client rejects write operations at the protocol layer
3. **Stdio JSON-RPC transport** with Docker isolation for deployment

The security validator is formalized: resolved path must remain a prefix of the sandbox root, or execution halts.

## Proof

| Operation | Latency | Memory |
|---|---|---|
| Handshake | 1.8ms | 12.4MB |
| Path boundary check | 0.05ms | 0.001MB |
| DB query (read-only) | 12.3ms | 4.2MB |

Sub-millisecond boundary assertions mean security checks don't become the bottleneck — they become invisible infrastructure.
