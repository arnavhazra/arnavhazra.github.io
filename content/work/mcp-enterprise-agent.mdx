## Every MCP server is a trust boundary

Agents now touch filesystems, databases, and internal APIs through Model Context Protocol servers. Directory traversal, over-scoped tokens, and missing audit trails are not edge cases — they are the default failure mode when MCP scales.

## What I built

An enterprise MCP server with three non-negotiable properties:

1. **Absolute path sandboxing** — every filesystem operation resolves against a fixed root; `../` triggers immediate abort
2. **Read-only database enforcement** at the protocol layer
3. **Docker-isolated stdio transport** for deployment

Security checks must be invisible to latency:

| Operation | Latency |
|---|---|
| Handshake | 1.8ms |
| Path boundary check | **0.05ms** |
| DB query (read-only) | 12.3ms |

## Stack

Node.js 20+, Docker 24+, PostgreSQL 15+
