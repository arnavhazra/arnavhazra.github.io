## The API tax on edge workloads

Frontier LLM APIs price per token and add network tail latency. For high-volume classification on Jetson-class hardware, a 1.58-bit model running locally can win on both economics and p99 — if the inference engine is tight enough.

## What I built

BitNet b1.58 constrains weights to {-1, 0, 1}, reducing matrix multiplication to integer accumulation with scale-back. Bare-metal C++/CUDA:

- Ternary weight packing into 2-bit uint8 arrays
- int8 activation quantization for bandwidth
- CUDA shared-memory GEMM with CPU fallback

## Measured

On NVIDIA Jetson Orin Nano (40W), batch-1 at 1024×2048:

- **0.88ms latency** at 135.2 GB/s memory bandwidth
- vs. 1.12ms on Apple M3 Max CPU at equivalent dimensions

No PyTorch runtime. No Python GIL. This is the SLM-vs-LLM decision made concrete.
