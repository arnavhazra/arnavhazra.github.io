## The failure mode of flat retrieval

"Where is DeepMind located?" is not a similarity problem. It is a path problem: Alice → works at → DeepMind → located in → London. Naive top-k retrieval returns the wrong chunk with high confidence.

## What I built

A hybrid engine that combines dense vectors (Qdrant), structured graph traversal (Neo4j), dynamic Cypher generation from resolved entities, and cross-encoder reranking on the union of both signals.

```
Document → entities → Neo4j
         → embeddings → Qdrant
Query → paths + vectors → rerank → LLM context
```

Relevance blends semantic similarity with path-weighted graph connectivity — tunable, not magic.

## Measured on the reference corpus

- Triple extraction: ~42ms per 1KB text
- Two-hop graph traversal: **3.4ms**
- Reranker throughput: 350 docs/sec

Docker Compose provisions Neo4j, Qdrant, and FastAPI together — reproducible, not a notebook demo.

## Stack

Python 3.11+, Neo4j 5.12+, Qdrant 1.6+, FastAPI 0.100+
