## Where agents actually fail

Most coding agents can produce syntax. Few can **converge** — they pass compilation, fail tests, burn context, and leave you with a diff you cannot trust. The engineering question is not "can it write code?" but "does the loop have a verifiable exit?"

## What I built

I modeled the workflow as an explicit LangGraph finite state machine: Planner → Coder → Tester → Reviewer, with programmatic routing back to Coder when a reflection quality score stays below threshold. Every revision runs inside a pytest sandbox; humans approve before anything merges.

The routing is deterministic:

```
Reviewer → Coder   if quality < 1.0 and iterations < I_max
Reviewer → End     otherwise
```

That single constraint turns an agent demo into something you can reason about in production.

## What it proved

- Four typed agent nodes with shared state (code diffs + verification logs)
- Documented self-correction: Reviewer flags missing error handling on pass one; pass two passes validation
- Graph topology you can test — not a black-box prompt chain

For teams evaluating agentic SWE, the win is **bounded iteration with measurable exit conditions**.

## Stack

Python 3.10+, LangGraph 0.0.10+, Pytest 7+
